## 📖 项目简介

这是一个用 **Canvas 动画** 一步步讲清楚 **FOC（磁场定向控制）** 从三相电流到双闭环 PI 控制完整链路的 **交互式教学网站**。

**适用于**：
- 🎓 电机控制专业的学生
- 🔧 嵌入式工程师（想做电机驱动）
- 📚 自动化/电气工程的老师（想找教学素材）
- 🤔 对 FOC 好奇但不知从哪入门的自学者

**核心特点**：
- **零依赖**：不用装 MATLAB、不用买开发板、不用配置环境
- **打开即用**：双击 HTML 就能看，无需服务器
- **中文**：国内稀缺的 FOC 中文可视化资源
- **交互式**：滑块拖动 → 实时看动画变化
- **体系完整**：从数学基础到硬件系统的完整链路

## 📚 内容结构（5 大部分 · 26 页）

### ① 坐标变换（01 ~ 07）

把三相交流量转成两相直流量——FOC 的数学基础。

| 编号 | 页面 | 核心内容 |
|------|------|---------|
| 01 | 三相电流 | 三个正弦波 + 脉振矢量 |
| 02 | 合成旋转矢量 | 三矢量合成 + 物理视角 |
| 03 | Clarke 变换 | 3 相 → 2 相（α-β） |
| 04 | Park 变换 ★ | α-β → d-q（FOC 灵魂） |
| 05 | 逆 Park | d-q → α-β |
| 06 | 逆 Clarke | α-β → 3 相 |
| 07 | 坐标变换总结 | 4 个变换全景 + 公式速查 |

### ② SVPWM 空间矢量调制（08 ~ 13）

把电压矢量翻译成 6 路 PWM。

| 编号 | 页面 | 核心内容 |
|------|------|---------|
| 08 | SVPWM 概念 | 输入 vα/vβ → 输出 6 路 PWM |
| 09 | 6 个基本矢量 | 逆变器开关状态 + 六边形 |
| 10 | 扇区判断 | Vref 落在哪个扇区 |
| 11 | 矢量合成 | T1/T2/T0 时间分配 |
| 12 | PWM 波形 | 6 路开关波形 + 上下桥臂互补 |
| 13 | 过调制 | 六边形内 vs 外（绿/黄/红） |

### ③ 控制（14 ~ 18）

开环、闭环、双闭环。

| 编号 | 页面 | 核心内容 |
|------|------|---------|
| 14 | 控制框图 | FOC 双闭环完整框图 |
| 15 | 开环控制 | V/F + 漂移 + 静差 |
| 16 | 电流环 | 内环 PI + 电流跟踪 |
| 17 | 速度环 | 外环 PI + 转速跟踪 |
| 18 | 双闭环 | 开环 vs 双闭环对比 |

### ④ PI 调参（19 ~ 21）

Kp / Ki 的影响与整定。

| 编号 | 页面 | 核心内容 |
|------|------|---------|
| 19 | PI 原理 | Kp / Ki 各自作用 |
| 20 | 速度环调参 | 4 组预设对比（慢/理想/超调/振荡） |
| 21 | 电流环调参 | 4 组预设对比 |

### ⑤ 综合与硬件（22 ~ 25）

编码器、综合演示、硬件系统、公式汇总。

| 编号 | 页面 | 核心内容 |

| 22 | 编码器与 θ 获取 | 增量 / 绝对 / 霍尔 / 无感 |
| 23 | 综合演示 | 一屏看全双闭环 |
| 24 | 硬件系统 | 电源 + 驱动板 + 控制板 + 电机 + 编码器 |
| 25 | 公式汇总 | 所有核心公式速查 |

## 📖 学习建议

**推荐顺序**（按页面编号）：
1. **第 1 部分**（01~07）：先理解坐标变换的数学基础
2. **第 2 部分**（08~13）：再理解 SVPWM 怎么把电压变成 PWM
3. **第 3 部分**（14~18）：理解控制结构（开环 → 闭环）
4. **第 4 部分**（19~21）：掌握 PI 调参
5. **第 5 部分**（22~25）：综合应用 + 硬件对照

**每个页面的学习方式**：
1. **先看动画** → 理解现象
2. **拖滑块** → 感受参数影响
3. **看公式** → 理解数学
4. **看底部知识点** → 总结本页
