核心公式
Te = 1.5·p·Ke·iq
J·dω/dt = Te − TL − B·ω
iq_ref = Kp_w·e_ω + Ki_w·∫e_ω
vd* = Kp_d·e_id + Ki_d·∫e_id
vq* = Kp_q·e_iq + Ki_q·∫e_iq
为什么 id_ref = 0？
表贴式 PMSM (Ld≈Lq) 的转矩仅由 iq 决定，
让 id = 0 可使同样电流产生最大转矩
(MTPA 特例)。内置式 PMSM (Ld<Lq)
或高速弱磁时，id 会取负值。
转速波形
知识点：闭环控制 = 双闭环：外环是速度环 PI（输入误差 ω_ref−ω，输出 iq_ref）， 内环是电流环 PI（d 轴和 q 轴各一个，输出 vd*/vq*）。d 轴参考值通常设 id_ref = 0（表贴式 PMSM）。 相比开环：id 被精确控到 0，iq 精确跟踪速度环输出，转速无静差。切到"开环"按钮可以直观对比—— 同样加负载，开环转速会掉，闭环瞬间恢复。电流环的带宽通常要比速度环快 5 倍以上，否则两环会互相干扰。
