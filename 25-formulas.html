① 坐标变换
Clarke 变换（3→2 相，等幅值）
iα = ia
iβ = (ia + 2·ib) / √3
把三相电流投影到 α-β 平面。合成矢量幅值 = 1.0·I（等幅值形式）。
Park 变换（α-β → d-q）
id = iα·cosθ + iβ·sinθ
iq = −iα·sinθ + iβ·cosθ
θ 是转子电角度（来自编码器/观测器）。旋转的 α-β 变成静止的 d-q。
逆 Park 变换（d-q → α-β）
vα = vd·cosθ − vq·sinθ
vβ = vd·sinθ + vq·cosθ
把 PI 算出的 d-q 电压指令转回 α-β 坐标，送给 SVPWM。
逆 Clarke 变换（2→3 相，等幅值）
va = vα
vb = −½·vα + (√3/2)·vβ
vc = −½·vα − (√3/2)·vβ
SVPWM 不需要逆 Clarke；传统 SPWM 才需要。
② SVPWM
扇区判断
θ = atan2(vβ, vα)
θ < 0 → θ += 2π
扇区 = ⌊θ / (π/3)⌋ + 1
六边形被分为 6 个扇形，每个 60°。
中间变量 X/Y/Z
X = √3 · vβ · Ts / Vdc
Y = (√3/2·vβ + 3/2·vα) · Ts / Vdc
Z = (√3/2·vβ − 3/2·vα) · Ts / Vdc
用于计算两个相邻基本矢量的作用时间。
T1/T2 时间分配（各扇区不同）
扇区 1: T1 = −Z, T2 = X
扇区 2: T1 = Z, T2 = Y
扇区 3: T1 = X, T2 = −Y
扇区 4: T1 = −X, T2 = Z
扇区 5: T1 = −Y, T2 = −Z
扇区 6: T1 = Y, T2 = −X
T0 = Ts − T1 − T2
T1 = 起始矢量作用时间，T2 = 结束矢量，T0 = 零矢量。
三相占空比（各扇区不同）
ta = (Ts − T1 − T2) / 2
tb = ta + T1
tc = tb + T2
然后按扇区映射到 Ta/Tb/Tc
最终三相占空比 = Ta/Tb/Tc / Ts。
过调制边界
内切圆 = Vdc / √3 ≈ 0.577 · Vdc
六边形顶点 = 2/3 · Vdc ≈ 0.667 · Vdc
|Vref| ≤ 内切圆：一定线性；内切圆 < |Vref| < 顶点：部分方向过调制；|Vref| > 顶点：完全过调制。
③ 控制
双闭环结构
速度环：iq_ref = PI_w(ω_ref − ω)
电流环：vd* = PI_d(id_ref − id)
　　　　vq* = PI_q(iq_ref − iq)
内环（电流）快，外环（速度）慢。内环带宽 ≥ 外环 5 倍。
电机电气方程
Ld·did/dt = vd − Rs·id + ωe·Lq·iq
Lq·diq/dt = vq − Rs·iq − ωe·Ld·id − ωe·Ke
ωe = ω · p（电角速度 = 机械角速度 × 极对数）。
电机机械方程
Te = 1.5 · p · Ke · iq　（表贴式）
J·dω/dt = Te − TL − B·ω
Te：电磁转矩；TL：负载转矩；J：转动惯量；B：摩擦系数。
④ PI 调参
PI 控制器
u = Kp·e + Ki·∫e dt
P 项对当前误差反应；I 项累积历史误差，消除静差。
调参经验
Kp ↑ → 响应快，但易超调/振荡
Ki ↑ → 消静差，但太大振荡、太小迟钝
先调 Kp 让响应快 → 再调 Ki 消静差
两个环：内环快（~10 kHz），外环慢（~1 kHz）。
⑤ 硬件 / 物理
6 个基本矢量
V1 = 100 → 0°
V2 = 110 → 60°
V3 = 010 → 120°
V4 = 011 → 180°
V5 = 001 → 240°
V6 = 101 → 300°
V0 = 000（零） V7 = 111（零）
1 = 上管开、下管关；0 = 上管关、下管开。
母线电流（简化）
Idc = 1.5 · (vd·id + vq·iq) / Vdc
从功率守恒推导：输入功率 ≈ 电磁功率 / 效率。
θ 获取 4 种方案
① 增量式编码器：计脉冲（高分辨率）
② 绝对式编码器：直接读（最高精度）
③ 霍尔传感器：60° 量化
④ 无感观测器：反电势/电流估算
成本 vs 精度 vs 复杂度，需权衡。
