FOC 的核心思想：把三相交流电机等效成直流电机来控制。 在 d-q 坐标系下，原本旋转的交流量变成了恒定的直流量——这就是 FOC 能用 PI 精确控制电流的根本原因。
三相电流 → Clarke → iα, iβ → Park → id, iq → PI 控制 → 逆 Park → 逆 Clarke → SVPWM → 逆变器 → 电机
↻ 编码器 / 观测器 → 提供 θ（转子角）、ω（速度）→ 供 Park / 逆 Park / 速度环使用
▸ 主线：SVPWM（空间矢量脉宽调制）—— 最常用
