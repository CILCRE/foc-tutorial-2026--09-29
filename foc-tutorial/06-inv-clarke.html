变换公式
va = vα
vb = −½·vα + (√3/2)·vβ
vc = −½·vα − (√3/2)·vβ
va + vb + vc = 0
逆 Clarke：把 α-β 平面的电压矢量，投影回三相绕组（a/b/c）。
输出三相电压 va/vb/vc，是时间上互差 120° 的正弦波。
输入 · 两相静止 (vα, vβ)
输出 · 三相电压 (va, vb, vc)
知识点：逆 Clarke 变换是 Clarke 的逆运算。Clarke 把三相 (a,b,c) 投影到两相 (α-β)， 逆 Clarke 把两相 (α-β) 投影回三相 (a,b,c)： va = vα，vb = −½vα + (√3/2)vβ，vc = −½vα − (√3/2)vβ。 输入 vα/vβ 是一个旋转的电压矢量，输出 va/vb/vc 是三个互差 120° 的正弦波。 注意：SVPWM 通常不需要逆 Clarke（直接用 vα/vβ）， 但传统 SPWM 需要 va/vb/vc（每相独立和三角波比较）。
