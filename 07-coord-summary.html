四个变换
① Clarke：a-b-c → α-β
② Park：α-β → d-q
③ 逆 Park：d-q → α-β
④ 逆 Clarke：α-β → a-b-c
为什么只用 2 个
三相电流 ia+ib+ic=0，所以 3 个量只有 2 个自由度——用 2 个正交分量（α-β）就能完全描述。 这就是 Clarke 把 3 变 2 的根本原因。

② 公式速查
① Clarke 变换（3→2 相，等幅值）
iα = ia
iβ = (ia + 2·ib) / √3
把三相电流投影到 α-β 平面。等幅值形式：合成矢量幅值 = 1.0·I。
② Park 变换（α-β → d-q）
id = iα·cosθ + iβ·sinθ
iq = −iα·sinθ + iβ·cosθ
θ 是转子电角度（来自编码器/观测器）。旋转的 α-β 变成静止的 d-q。
③ 逆 Park 变换（d-q → α-β）
vα = vd·cosθ − vq·sinθ
vβ = vd·sinθ + vq·cosθ
把 PI 算出的 d-q 电压指令转回 α-β 坐标，送给 SVPWM。
④ 逆 Clarke 变换（2→3 相，等幅值）
va = vα
vb = −½·vα + (√3/2)·vβ
vc = −½·vα − (√3/2)·vβ
把 α-β 电压矢量投影回三相。传统 SPWM 用这个。
③ 每个变换"用在哪"
Clarke
输入：ia, ib, ic（电流采样）
输出：iα, iβ
在哪：电流环的反馈通道
频率：与 PWM 同步（~10-20 kHz）
Park
输入：iα, iβ + θ
输出：id, iq
在哪：电流环的反馈通道
频率：与 PWM 同步
逆 Park
输入：vd*, vq* + θ
输出：vα, vβ
在哪：电流环的输出通道
频率：与 PWM 同步
逆 Clarke
输入：vα, vβ
输出：va, vb, vc
在哪：SPWM 用；SVPWM 不用
频率：与 PWM 同步
④ 记忆口诀
Clarke：3 变 2（相数减少）
Park：转坐标（静止 → 旋转）
逆 Park：转回来（旋转 → 静止）
逆 Clarke：2 变 3（相数恢复）
⚡ 口诀：
Clarke 减相 → Park 转轴 → PI 在 d-q 里算 → 逆 Park 转回 → 逆 Clarke 复相
本部分小结：坐标变换是 FOC 的数学基础。通过 4 个变换（Clarke / Park / 逆 Park / 逆 Clarke）， 把三相交流电机的控制问题，转化为"在旋转 d-q 坐标系里控制两个直流量"的问题—— 这就是 FOC 能用简单 PI 调节器精确控制电流的根本原因。 下一步：进入第二部分 SVPWM，看怎么把 vα/vβ 变成 6 路 PWM。
